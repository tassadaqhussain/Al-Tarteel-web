## 1. Google Guidance Verification Report (October 2026)
- **Verified Guidance:** Current Google Search Essentials, crawler directives (meta robots, X-Robots-Tag, robots.txt), Google Search Console sitemap requirements, Schema.org structured data documentation, Core Web Vitals (INP, LCP, CLS), and Google Analytics 4 Measurement Protocol / Consent Mode v2.
- **Recent Google Search Changes Confirmed:**
  - **FAQ rich results:** Deprecated / restricted by Google to authoritative government/health websites. Deprecated FAQ schemas avoided.
  - **Course / ClaimReview / Learning Video:** Deprecated for general markup; standard `LearningResource` / `CreativeWork` and `Article` schema utilized.
  - **Breadcrumbs:** Mobile breadcrumb displays simplified; desktop structured data requires valid hierarchical `BreadcrumbList` without broken target URLs.
  - **lastmod in Sitemaps:** Google ignores unverified/fabricated modification timestamps. Truthful timestamps only; fabricated dates strictly omitted.
  - **Robots.txt:** Google ignores non-standard `Host:` directives and `<priority>` / `<changefreq>` tags in sitemaps. Clean `<loc>` elements retained.
  - **Consent Mode v2:** Mandatory for traffic in the EEA/UK to preserve accurate modeling and tracking without privacy violations.

## 3. Implementation Details by Phase

### Phase 2: Google Analytics 4 Integration
1. **Dynamic Measurement ID:** Reads exclusively from `process.env.NEXT_PUBLIC_GA_MEASUREMENT_ID`. Gracefully disables when unset.
2. **Consent Mode v2:** Default state denies advertising storage, user data, and personalization while granting anonymous analytics storage with a 500ms update window before the tag executes.
3. **Double Page View Prevention:** Configured `send_page_view: false` in `gtag('config')`, giving `RouteChangeTracker` sole control over page views with built-in URL deduplication.
4. **Enhanced Measurement & Outbound Link Tracking:** Added global passive click listener for external domain links (`click` event with `outbound: true`).
5. **Business Event Instrumentation:**
   - `login` (`method: 'email'`) in `src/app/(auth)/login/page.tsx`
   - `sign_up` (`method: 'email'`) in `src/app/(auth)/register/page.tsx`
   - `search` (`search_term`, `search_type`, `results_count`) in `SmartSearchBox.tsx` and `src/app/search/page.tsx`
   - `select_content` for reciters, translation slugs, and learning plan days
   - `audio_play` and `audio_complete` in `AudioPlayerProvider.tsx`
   - `begin_checkout` in `DonateCheckoutForm.tsx` and `purchase` on `src/app/donate/success/page.tsx`
   - `share` in `ShareVerseModal.tsx` for social and link copy actions
   - `form_submit` in `src/app/feedback/page.tsx`

### Phase 3 & 4: Google Search Console & Dynamic Page-Level SEO
1. **Search Console Ownership Verification:** Supported via `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` in `src/app/layout.tsx`.
2. **XML Sitemap Architecture:** Clean sitemap index at `/sitemap.xml` linking 4 specialized shards (`/sitemap/0.xml` to `/sitemap/3.xml`) containing all 627 indexable canonical URLs without fabricated dates.
3. **Robots.txt Directives:** Allows crawling of indexable and noindex public pages (`/login`, `/search`, etc.) so search engines process the `noindex` tag, while blocking administrative endpoints (`/admin`, `/api/`, `/donate/checkout`).
4. **Prerendered Learning Plans:** Restructured `src/app/learning-plans/[slug]/page.tsx` into a static-generated route (`generateStaticParams`) with individual titles, descriptions, canonical URLs, and Open Graph metadata.

### Phase 5: Structured Data
- **Organization & WebSite:** Configured globally in root layout with site URL, logo, and descriptions.
- **BreadcrumbList:** Rendered across Surah pages, Ayah pages, Juz pages, Articles, Learning Plans, and Tajweed lessons.
- **CreativeWork & LearningResource:** Implemented for Ayahs, Surahs, and Learning Plans.
- **Article Schema:** Rendered for educational articles and Tajweed lessons.

### Phase 6: Core Web Vitals & Performance
- **Server Prerendering Optimization:** Eliminated server-side `cookies()` read on `/juz/[number]`, enabling full static generation (`force-static`) during build and sub-100ms response times.
- **Resource Prioritization:** Added preconnect and dns-prefetch links for `googletagmanager.com`.
- **CLS Protection:** Maintained explicit dimensions and responsive sizes on site logos, hero images, and cards.

### Phase 9: Security & Privacy
- **Sanitization Engine:** `sanitizeUrl()` strips 14+ authentication tokens and query parameters (`token`, `auth`, `password`, `key`, `secret`, `email`, `session_id`, `payment_intent_client_secret`).
- **PII Redaction:** `sanitizeText()` redacts email address patterns from search strings and page URLs.
- **Safe Execution:** All analytics calls run in passive try/catch blocks to ensure tracking errors never interrupt user experience.
