# QuranPilot SEO review — 14 September 2026

Reviewed live HTML, HTTP responses, titles, descriptions, canonical URLs, robots directives, sitemap shards, verse content and navigation, alongside the Next.js source. This is a technical audit, not a Search Console ranking or Core Web Vitals report. Changes below are in the working tree and require deployment.

## Confirmed issues and changes

| Priority | Live evidence | Implemented change |
| --- | --- | --- |
| High | `/al-baqarah?page=8` promises verses 281–286 but renders 43–48; `/al-kahf?page=3` promises 81–110 but renders 61–90. | Keep the API pagination limit constant. The backend calculates the offset from page and limit; reducing the final limit fetched the wrong verses. |
| High | `/al-baqarah?page=2` and its Urdu counterpart return distinct verses 41–80 but carry `noindex`. | Allow indexing of distinct verse slices, retaining self-canonicals and adding reciprocal hreflang links for the same page in all four languages. |
| Medium | `/ur/al-baqarah/255` links to `/ur/surahs`, which returns 404. Language switching also manufactured nonexistent localized article and tool URLs. | Point localized verse breadcrumbs to the existing language hub; only prefix routes that actually have translations. |
| Medium | `/al-baqarah/255junk` returns HTTP 200 and the content of verse 255. | Reject malformed/out-of-range verse segments and redirect zero-padded verse numbers and noncanonical slug casing. |
| Medium | Every URL in each sitemap uses its shard generation timestamp as the content modification date. | Omit unsupported `lastmod` values. Add them only when actual significant content revision dates are tracked. |
| Medium | The locale sitemap lists chapters but none of the translated featured verse pages. | Add 45 existing localized verse URLs, including Ayatul Kursi. |
| Medium | Localized verse descriptions begin with English copy. | Use Urdu, Pashto and Persian descriptions naming the translation language. |
| Medium | The shared footer does not link to the language hubs, article library or tajweed guide. | Add crawlable links to those existing resources. |

## Validation

- `node scripts/test-seo.cjs`: covers all 219 verse slices across 114 surahs, four-language canonical/indexing metadata, malformed verse segments, language-switch destinations and 619 unique sitemap URLs.
- `./node_modules/.bin/tsc --noEmit`: passed before production build.
- `API_URL=https://quranpilot.com/api/v1 npm run build` (from `frontend`): passed, including TypeScript and 763 generated pages.
- Local production HTTP checks passed: English/Urdu final-page verse ranges and indexing, invalid verse 404s, canonical 308 redirects, corrected breadcrumb and all five sitemap XML responses.
- Browser verification confirmed verses 281–286 and the footer layout.
