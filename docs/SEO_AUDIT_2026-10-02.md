## Outdated local rule

- Existing: `seo.ts` said x-default is "required for Google to honour the cluster".
- Current guidance: annotations must be reciprocal and self-referencing; x-default is a recommended fallback, not a requirement.
- Replaced with the current wording.

## Not changed (needs a decision or data)

- Public reader pages send `Cache-Control: private, no-store`, and long pages ship 500–600 KB of uncompressed HTML. Decision (2 Oct 2026): leave as is until Core Web Vitals are measured. Causes, for whoever revisits it:
    - Surah pages render per request because `?page=N` pagination reads `searchParams`; their HTML does not vary by visitor (cookies are deliberately not read).
    - Juz pages also read the translation cookie and render verses server-side only, so dropping the cookie read would break the reader's chosen translation without making them cacheable.
    - Options if needed: an nginx micro-cache for anonymous full-page requests (must bypass Next's RSC navigation requests), or path-based pagination (changes indexed URLs; needs redirects and canonical/hreflang/sitemap updates).
- About 25,000 indexable ayah pages (6,236 × 4 locales); review Search Console coverage before any indexing change.
- Translator id 94 ("Hussein Taji Kal Dari", language `fa`) has slug `fr-hussein-taji`. Data owner to confirm; not edited.
- `CreativeWork` JSON-LD on surah/ayah pages is truthful but enables no Google feature; kept.

Regression checks added to `frontend/scripts/test-seo.cjs`. Sitemap: 628 URLs (627 live + `/learn-namaz`). Changes require deployment.
